MIGRATION GUIDE · VAJ → NIX

Move from VAJ to the Nix edition.

The VAJ edition is deprecated after v0.2.34-vaj. Back up its home directory, install the Nix edition, then restore your files into the new app.

Both apps can stay installed at the same time, so you can verify the Nix setup before removing VAJ.

Why migrate

Active maintenance of the VAJ apt repository at repo.pathayam.xyz is ending. The Nix edition replaces that repository with Nix packages and a Nix binary cache, providing a maintained package path without continuing the separate VAJ apt ecosystem.

1. Back up your VAJ home

In the VAJ terminal, allow storage access if needed, then create an archive on shared storage:

tar -czf /sdcard/vaj-backup.tar.gz -C /data/data/io.vaj.tl/files home

Keep this archive until you have checked that the migration is complete.

2. Install the Nix edition

Open Termux Launcher releases, choose a release whose tag ends in -nix (for example, vX.Y.Z-nix), and install its Nix edition APK. Its Android package is com.termux.launcher.nix.

The first boot downloads the Nix-on-Droid bootstrap. Let it finish before restoring your home directory.

3. Restore your home

In the Nix edition terminal, restore the archive into the new app data directory:

tar -xzf /sdcard/vaj-backup.tar.gz -C /data/data/com.termux.launcher.nix/files

Restore home only, not usr. Packages now come from Nix, and copying VAJ's apt-managed usr tree would mix incompatible environments.

4. Reinstall packages with Nix

Where VAJ used pkg install X, add the package to environment.packages in ~/.config/nixpkgs/nix-on-droid.nix:

{ pkgs, ... }:
{
  environment.packages = with pkgs; [
    X
  ];
}

Apply the configuration:

nix-on-droid switch

Replace X with the corresponding Nix package attribute. Repeat the switch after changing the package list.

5. Verify before removing VAJ

Open your restored files, rebuild the packages you need, and confirm your shell configuration works. Because io.vaj.tl and com.termux.launcher.nix are different Android packages, both apps can coexist throughout the migration.
